# The map and the list

The map is your home screen. It shows the features of your role.

- **Zoom limits:** If your project sets a lowest or highest zoom level (Project settings, Default view), the map never goes beyond it, not even when it fits to features or centres on one.
- **Opening view:** The map opens at your project's start view (Project settings, Default view). If the project has none and your start view shows only features without a position (for example work orders), it opens where the earlier app opened without a setting (7.45 / 51.505, zoom 13); otherwise it fits to the features. When the features of a large project arrive on the device bit by bit, the view grows with them until the data is there (about 5 seconds without news) or you move the map yourself; filters do not change the view afterwards.
- **Groups:** Features close together are grouped into one number. One tap on the number opens the group sheet (see below); a second tap right after it zooms to the group's features.
- **Pan and zoom:** One finger moves the map, two fingers zoom. The map never rotates. **Location** in the bar centres the map on your position and shows the dot and the accuracy circle; if the device cannot tell where you are, a short message says so and the map stays. Screen readers announce the map.
- **Open a feature:** Tap a feature to open its sheet. Areas and lines can be tapped themselves; their marker always sits inside the area.
- **List instead of map:** The **List** button at the top left of the map shows the same features as a list, namely those in the current map extent. If the map cannot be shown (for example no WebGL), the list stands in its place by itself, with the reason. Features without a position (for example a work order) are always in the list, because they are not on the map. The first column names each feature by its required text field (for example its name); a feature whose type has none is named by its type and the last characters of its id, for example *Tree #4f2a*. Tap a column heading to sort; a second tap reverses the order. With the keyboard, move to a feature with Tab and open it with Enter. The list is also meant for screen readers.
- **Group sheet:** One tap on a group opens a sheet with its make-up: the number of features on top, then one block per feature type with a row per value (per stage, or per value of the property the type is told apart by on the map; a colour dot in the colour the map draws it in, name, count, bar and percent). On a phone the sheet starts half-height (a tap or drag on its header makes it taller); on a desktop it is a side panel on the right. Tap a row and the map shows only that row's features, one by one, and zooms to them; tap the same row again, **Close**, or the empty map, and the map returns to its earlier view. Tap a single feature and its sheet opens.
- **Zoom into a group:** Tap the number twice quickly: the map fits the group's features and zooms in to level 18 at most.
- **Icons and colours by value:** Your project can draw features with their own icon and colour by stage or by another property (for example a red warning triangle for open defects). Areas and lines take the same colour. A value with no icon of its own uses the feature type's icon, otherwise a coloured dot. The group circles stay grey.
- **Colours and shapes:** A view can define its own look for features (for example a colour by status). Ask your administrator if the map looks different in another view.
