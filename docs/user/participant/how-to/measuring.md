# Eine Strecke oder Fläche messen

Das Werkzeug **Messen** auf der Karte zeigt, wie lang ein Weg oder wie groß eine Fläche ist. Es misst nur. Es verändert nie ein Objekt.

> Hinweis: Ihr Projekt kann **Messen** anbieten, ohne es einzuschalten. Dann schalten Sie es selbst ein: **Einstellungen**, Reiter **Optionen**, **Erweiterte Funktionen**, Schalter **Messen**. Erst danach gibt es das Werkzeug unter **Werkzeuge**.

1. Öffnen Sie auf der Karte **Werkzeuge** und tippen Sie auf **Messen**. Das Fenster zeigt **Strecke** und **Fläche**; wählen Sie eines.
2. Tippen Sie jeden Punkt auf der Karte an, oder gehen Sie hin und tippen Sie auf **Meine Position hinzufügen** (beim ersten Mal fragt Ihr Gerät nach der Erlaubnis).
3. Das Ergebnis erscheint sofort. Bei einer Strecke sehen Sie die Gesamtlänge und die letzte Teilstrecke. Bei einer Fläche sehen Sie die Fläche und ihren Umfang. Eine Strecke braucht zwei Punkte, eine Fläche drei.
4. **Rückgängig** entfernt den letzten Punkt. **Leeren** entfernt alle Punkte und die Linie oder Fläche auf der Karte.

Gut zu wissen:
- Längen erscheinen in Metern oder Kilometern, Flächen in Quadratmetern, Hektar oder Quadratkilometern.
- Überschneidet sich der Umriss einer Fläche, sagt das Fenster es und misst nicht. Machen Sie den letzten Punkt rückgängig oder leeren Sie.
- Die Werte sind dieselben, die das Projekt für seine eigenen Objekte verwendet.
- Messen funktioniert ohne Verbindung.
- **Messen** erscheint unter **Werkzeuge**, solange die Karte angezeigt wird. Steht die Liste für die Karte (die Karte konnte nicht gezeichnet werden, oder Sie haben mit **Liste** umgeschaltet), wird es nicht angeboten: es gibt nichts zum Antippen. Schalten Sie zur Karte zurück, ist es wieder da.
- Das Fenster sitzt unten und dunkelt die Karte nicht ab: Sie können weiter die Karte darüber antippen. **Schließen** (das X) schließt das Fenster und entfernt die Linie von der Karte.
- Ein Tipp auf ein Objekt öffnet das Objekt und setzt keinen Punkt. Tippen Sie auf die leere Karte zwischen den Objekten.
