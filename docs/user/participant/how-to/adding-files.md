# Dateien hinzufügen

Manche Formulare haben ein Dateifeld mit der Schaltfläche **Dateien** (zum Beispiel für PDFs oder Pläne).

1. Tippen Sie auf **Dateien** und wählen Sie eine oder mehrere Dateien von Ihrem Gerät (mehrere nur, wenn das Feld mehr als eine Datei erlaubt).
2. Die Meldung „Hinzugefügt“ erscheint, und jede Datei steht mit ihrem Namen in der Liste über der Schaltfläche. Mit dem x an einer Datei entfernen Sie sie wieder.
3. Die Dateien kommen zu den vorhandenen hinzu, bis zum Maximum, das das Projekt für dieses Feld festlegt (10, wenn nichts anderes steht). Dann ist die Schaltfläche aus und eine Meldung sagt es.

Gut zu wissen:
- Dateien funktionieren ohne Verbindung. Sie werden auf Ihrem Gerät gespeichert und später mit der Aufgabe gesendet.
- Das Projekt legt die erlaubten Dateitypen fest. Eine Datei eines anderen Typs wird abgelehnt, mit einer Meldung. Legt das Projekt keine Typen fest, bietet die Auswahl Bilder an (PNG, JPEG, WebP, GIF).
- Anders als bei Fotos wird die Datei unverändert gespeichert.
- Alles funktioniert mit der Tastatur: Mit Tab erreichen Sie die Schaltfläche, mit Enter oder Leertaste öffnen Sie die Auswahl.
