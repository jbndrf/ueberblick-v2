# Eine Linie oder Fläche auf der Karte zeichnen

Manche Objektarten sind eine Linie (zum Beispiel eine Hecke oder ein Zaun) oder eine Fläche (zum Beispiel eine beschädigte Stelle). Sie zeichnen sie direkt auf der Karte, mit dem Kartenhintergrund unter dem Finger.

1. Tippen Sie unten auf **+** und dann auf die Objektart. Die Karte bleibt, die Leiste unten verschwindet, und oben rechts (unter der Kopfzeile) erscheint eine Reihe grauer Knöpfe. Ein Tipp auf die Karte setzt nur einen Punkt, er schließt das Zeichnen nicht.
2. Tippen Sie auf die Karte, um einen Punkt zu setzen. Eine Linie braucht zwei Punkte, eine Fläche drei. Das aktive Element wird rot gezeichnet, der Umriss einer unfertigen Fläche gestrichelt.
3. Um einen Punkt zu verschieben, ziehen Sie ihn. Bei einer Fläche schließt ein Tipp auf den **ersten Punkt** den Umriss.
4. Tippen Sie auf **Fertig** (der grüne Haken), wenn die Form vollständig ist. Das Formular öffnet sich mit der Form darin. Das Kreuz oben bricht das Zeichnen ab.

Die Knöpfe von oben nach unten:
- **Abbrechen** (Kreuz): verlässt das Zeichnen, ohne etwas zu behalten.
- **Neues Element** (Plus) und die nummerierten Knöpfe **Element 1, 2, …**: nur für Objektarten, die aus mehreren Teilen bestehen dürfen (zum Beispiel eine Hecke mit Lücke). **Neues Element** beginnt einen weiteren Teil; ein nummerierter Knopf macht diesen Teil zum aktiven, sodass Sie weitere Punkte hinzufügen können.
- **Rückgängig** und **Wiederherstellen**: gehen im aktiven Element eine Änderung zurück oder vor. Sie erscheinen nur, wenn es etwas zurückzunehmen oder wiederherzustellen gibt.
- **Element löschen** (Papierkorb): entfernt das aktive Element und nummeriert die übrigen neu.
- **Fertig**: grau, bis ein Element genug Punkte hat.

Gut zu wissen:
- Ist die Form ungültig, zum Beispiel eine Fläche mit sich kreuzenden Kanten, sagt **Fertig** „Nicht übernommen: …“ mit dem Grund, und die Zeichnung bleibt wie sie ist. Verschieben Sie einen Punkt oder tippen Sie auf **Rückgängig**.
- Kleine technische Probleme werden für Sie behoben, zum Beispiel die Richtung, in der eine Fläche gezeichnet ist.
- Objektarten ohne mehrere Teile zeigen nur eine Form: es gibt kein **Neues Element**.
- Ein Geometriefeld in einem Formular zeigt nur, was gezeichnet wurde („Fläche: 1 Teil(e), 4 Punkte“); gezeichnet wird immer auf der Karte.

## Einen Standort oder eine Form ändern (zum Beispiel Baum verschieben)
Eine Aufgabe, die nur den Standort ändert, öffnet kein Formular, sondern geht direkt auf die Karte. Der Pin beginnt am bisherigen Standort, bei einer Linie oder Fläche ist die bisherige Form schon geladen.
1. Tippen Sie am Objekt auf die Aufgabe (zum Beispiel **Baum verschieben**). Das Blatt tritt zur Seite und die Leiste unten verschwindet.
2. Ziehen Sie den Pin oder tippen Sie auf die neue Stelle; bei einer Linie oder Fläche ziehen Sie die Punkte oder zeichnen neu.
3. Bestätigen Sie mit dem roten Knopf (dem Namen der Aufgabe) oder mit **Fertig**. Es wird genau eine Änderung gespeichert. Das Kreuz bricht ab, ohne etwas zu schreiben, und das Blatt kommt zurück.
Lehnt der Server die Änderung ab, steht der Grund im Hinweis unten rechts. Hat die Aufgabe noch weitere Felder, öffnet sich nach der Karte das Formular mit der neuen Position.
