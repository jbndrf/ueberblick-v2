# Ein Foto hinzufügen

Manche Formulare haben ein Foto-Feld. Es zeigt zwei Schaltflächen.

1. Tippen Sie auf **Foto aufnehmen**, um die Kamera zu öffnen, oder auf **Foto auswählen**, um ein Bild von Ihrem Gerät zu wählen.
2. Warten Sie einen Moment. Das Foto wird zuerst auf Ihrem Gerät verkleinert; Screenreader hören „Foto wird verarbeitet …“ und „Foto hinzugefügt“, und die Vorschau erscheint in der Galerie über den Schaltflächen.
3. Um ein weiteres Foto hinzuzufügen, tippen Sie erneut auf eine der Schaltflächen. Jedes Foto kommt zu den vorhandenen hinzu, bis zum Maximum, das das Projekt für dieses Feld festlegt (10, wenn nichts anderes steht); dann sind die Schaltflächen aus und eine Meldung sagt es.
4. **Foto auswählen** lässt Sie mehrere Fotos auf einmal wählen, wenn das Feld mehr als eines aufnimmt. Sie werden nacheinander in der Reihenfolge Ihrer Auswahl hinzugefügt. Wählen Sie mehr, als noch Platz haben, werden die ersten hinzugefügt und die übrigen weggelassen. **Foto aufnehmen** macht ein Bild nach dem anderen.

Gut zu wissen:
- Fotos funktionieren ohne Verbindung. Sie werden auf Ihrem Gerät gespeichert und später mit der Aufgabe gesendet.
- Ihr Standort wird **nicht** mit dem Foto gespeichert, es sei denn, das Projekt erlaubt es für dieses Feld.
- Das Foto wird als JPEG gespeichert und auf eine für das Projekt passende Größe verkleinert.
- Kann ein Foto nicht verarbeitet werden, erscheint eine Meldung; versuchen Sie ein anderes Bild.
- Alles funktioniert mit der Tastatur: Mit Tab erreichen Sie die Schaltflächen, mit Enter oder Leertaste öffnen Sie die Auswahl.
- Ein Feld kann mehrere Fotos oder Dateien aufnehmen. Das Projekt legt das Maximum (10, wenn nichts anderes gesetzt ist) und die erlaubten Dateitypen fest. Eine Datei über dem Maximum oder eines nicht erlaubten Typs wird an diesem Feld abgelehnt.
