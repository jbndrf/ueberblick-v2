# Searching for a feature

The **Search** tool on the map finds features by text, for example a tree number or a street. It works on this device, so it works without a connection.

> Note: If **Search** is not under **Tools**, your project offered it but did not switch it on. Switch it on yourself: **Settings**, tab **Options**, **Advanced features**, switch **Search**.

1. On the map, open **Tools** and tap **Search**.
2. Start typing. Results appear with every letter. Capital letters and accents do not matter: `baume` finds `Bäume 12`. Type the beginning of a word; with several words, every word must match the beginning of a word in the feature.
   Each result shows the matched text and, below it, the name of the feature type. A screen reader reads both, separated by a comma.
3. Tap a result. The map moves to the feature and its feature sheet opens. If your device is set to reduce motion, the map jumps there instead of gliding.

Good to know:
- Which fields are searched is set by the project. If the panel says no search fields are configured, ask the person who sets up the project.
- Only the first 20 results are shown. Type more to narrow them down.
- A feature whose type has no map position still opens; the map stays where it is and a note says so.
- Keyboard: Enter opens the first result, the arrow keys move through the list, Escape clears the search.
- Features you created or changed on this device and have not sent yet are found too.
