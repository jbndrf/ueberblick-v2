# Neues Objekt anlegen

1. Tippen Sie unten auf **+** (am Computer oben in der Kopfzeile). Sie sehen eine Auswahl: pro Objektart, die Ihre Rolle anlegen darf, ein Knopf (mit dem Namen der Aufgabe).
2. Tippen Sie auf die Objektart.
3. Hat die Objektart einen Punkt auf der Karte, erscheint ein **roter Pin** in der Kartenmitte und unten ein roter Knopf mit dem Namen der Aufgabe. Ziehen Sie den Pin auf die genaue Stelle, oder tippen Sie auf die Karte, um den Pin dorthin zu setzen; eine gestrichelte Linie verbindet den roten Knopf mit dem Pin. Dann tippen Sie auf den roten Knopf. Das **x** daneben bricht ab.
4. Das Formular öffnet sich an dieser Stelle, mit dem Pin als Standort. Hat die Objektart keinen Ort, öffnet sich das Formular sofort nach Schritt 2.

**Mit Eltern-Element verketten:** Gehört die Objektart zu einem übergeordneten Objekt (zum Beispiel ein Baum zu einem Gebiet) und ist die Verknüpfung nicht Pflicht, steht beim Setzen des Pins oben rechts ein Kettensymbol. Tippen Sie darauf: Ein Hinweis „Tippe auf das Eltern-Element“ erscheint, und jedes mögliche Eltern-Element im Kartenausschnitt bekommt einen Ring. Tippen Sie auf einen Ring: Der Pin springt auf das Eltern-Element, eine gestrichelte Linie verbindet beide, und das Formular öffnet sich mit dem verknüpften Eltern-Element. Ein zweiter Tipp auf das Kettensymbol hebt die Verknüpfung wieder auf; Sie legen das Objekt dann für sich allein an.

**Objektarten, die am Eltern-Element sitzen** (zum Beispiel eine Maßnahme am Baum) haben keinen eigenen Ort und keinen Pin. Nach dem Tipp auf die Objektart erscheinen der Hinweis und die Ringe sofort; ein Tipp auf das Eltern-Element öffnet das Formular mit dem verknüpften Eltern-Element. „Abbrechen“ unten bricht ab. Aus dem Objekt selbst legen Sie solche Unterobjekte mit „{Name} anlegen“ an, dann entfällt das Antippen.

Objektarten, die eine Linie oder Fläche sind, zeichnen Sie statt des Pins direkt auf der Karte: Punkte antippen, dann **Fertig**; das Formular öffnet sich mit der Form. Siehe [Eine Linie oder Fläche auf der Karte zeichnen](drawing-a-geometry.md).

Solange der Pin gesetzt wird, ist die untere Leiste ausgeblendet. Haben Sie die Höchstzahl an Einträgen erreicht, die Ihre Rolle anlegen darf, sind die Knöpfe grau und ein Hinweis sagt, dass Sie zuerst einen Eintrag löschen müssen. Ein Tipp neben die Auswahl schließt sie (und „Zuletzt“, falls es offen ist).

## Zuletzt
Ist „Zuletzt“ offen, rückt die Auswahl in die linke Hälfte.
Tippen Sie ein zweites Mal auf **+** (am Computer auf die Uhr), um **Zuletzt** zu öffnen: die 50 Objekte, die zuletzt verändert wurden. Ein Tipp auf eine Zeile fliegt zum Objekt und öffnet es. Objekte ohne Ort (**ohne Ort**) erreichen Sie nur hier und über die Liste.

Jede Zeile zeigt das Symbol oder die Farbe der Objektart (wie auf der Karte), die Objektart, was zuletzt getan wurde (zum Beispiel „3 Felder aktualisiert“, „Standort aktualisiert“, „Statuswechsel: Prüfung“), den Namen des Objekts, wie lange das her ist, und seine Stufe. Diese Zeile erscheint einen Moment nach dem Öffnen der Liste.
