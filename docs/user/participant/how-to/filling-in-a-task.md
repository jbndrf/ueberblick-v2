# Eine Aufgabe ausfüllen

Sie öffnen eine Aufgabe im Objektblatt oder über das Plus auf der Karte. Das Formular öffnet sich im selben Fenster wie das Objektblatt.

1. Füllen Sie die Felder von oben nach unten aus. Felder, die nicht zur Situation passen, sind ausgeblendet und erscheinen von selbst, sobald sie gebraucht werden. Ausgeblendete Felder werden nicht gespeichert.
2. Vorausgefüllte Werte (zum Beispiel der bisherige Zustand) können Sie jederzeit ändern. Ihre Änderung bleibt bestehen.
3. Pflichtfelder tragen einen roten Stern. Fotos, Positionen und ähnliche Eingaben nehmen Sie über das jeweilige Werkzeug im Feld auf.
4. Hat das Formular mehrere Seiten, tippen Sie unten auf **Weiter**. **Zurück** behält alles, was Sie eingegeben haben.
5. Tippen Sie auf **Absenden** (oder **Weiter**). Stimmt etwas nicht, erscheint oben eine Liste der Probleme. Ein Tipp auf einen Eintrag springt zum Feld.

Die Schaltfläche unten ist groß und mit dem Daumen erreichbar. Alles lässt sich auch mit der Tastatur bedienen.

## Entwürfe, offline und Ablehnungen

- **Entwürfe:** Ihre Eingaben werden etwa eine Sekunde nach der letzten Änderung und beim Schließen des Blatts als Entwurf auf diesem Gerät gespeichert, auch wenn das Telefon die App beendet. Öffnen Sie dieselbe Aufgabe wieder, sind Ihre Eingaben zurück („Ihr Entwurf wurde wiederhergestellt“). Mit dem Absenden verschwindet der Entwurf.
- **Nach dem Absenden:** Sobald die Änderung auf dem Gerät gespeichert ist, schließt sich das Formular, online wie offline; der Entwurf verschwindet. Am Objekt steht „Noch nicht übertragen: n.“, bis der Server die Änderung angenommen hat.
- **Nicht möglich:** Lehnt schon Ihr Gerät die Aufgabe ab, bleibt das Formular mit Ihren Eingaben offen, und ein rotes Feld „Nicht möglich“ nennt den Grund; es wurde nichts gespeichert. **Schließen** blendet das Feld aus.
- **Abgelehnt:** Lehnt der Server die Aufgabe später ab, zeigt das Objekt „Abgelehnt“ mit dem Grund, **Erneut senden** und **Verwerfen**. Dasselbe steht unter Einstellungen, Profil, „Ausstehende Änderungen“ (siehe [Wenn eine Übermittlung abgelehnt wird](../refused-runs.md)).
