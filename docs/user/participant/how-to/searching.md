# Ein Objekt suchen

Das Werkzeug **Suche** auf der Karte findet Objekte über Text, zum Beispiel eine Baumnummer oder eine Straße. Es arbeitet auf diesem Gerät und funktioniert daher ohne Verbindung.

> Hinweis: Steht **Suche** nicht unter **Werkzeuge**, hat Ihr Projekt sie angeboten, aber nicht eingeschaltet. Schalten Sie sie selbst ein: **Einstellungen**, Reiter **Optionen**, **Erweiterte Funktionen**, Schalter **Suche**.

1. Öffnen Sie auf der Karte **Werkzeuge** und tippen Sie auf **Suche**.
2. Beginnen Sie zu tippen. Mit jedem Buchstaben erscheinen Treffer. Groß- und Kleinschreibung sowie Akzente spielen keine Rolle: `baume` findet `Bäume 12`. Tippen Sie den Anfang eines Wortes; bei mehreren Wörtern muss jedes Wort am Anfang eines Wortes im Objekt passen.
   Jeder Treffer zeigt den gefundenen Text und darunter den Namen der Objektart. Ein Screenreader liest beides, getrennt durch ein Komma.
3. Tippen Sie auf einen Treffer. Die Karte fährt zum Objekt und sein Objektblatt öffnet sich. Ist an Ihrem Gerät reduzierte Bewegung eingestellt, springt die Karte, statt zu gleiten.

Gut zu wissen:
- Welche Felder durchsucht werden, legt das Projekt fest. Sagt das Fenster, dass keine Suchfelder eingerichtet sind, fragen Sie die Person, die das Projekt einrichtet.
- Es werden nur die ersten 20 Treffer gezeigt. Tippen Sie mehr, um einzugrenzen.
- Ein Objekt, dessen Typ keine Kartenposition hat, öffnet sich trotzdem; die Karte bleibt stehen und ein Hinweis sagt es.
- Tastatur: Eingabe öffnet den ersten Treffer, die Pfeiltasten bewegen sich durch die Liste, Escape leert die Suche.
- Objekte, die Sie auf diesem Gerät angelegt oder geändert und noch nicht gesendet haben, werden ebenfalls gefunden.
