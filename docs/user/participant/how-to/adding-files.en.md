# Adding files

Some forms have a file field with a **Files** button (for example for PDFs or plans).

1. Tap **Files** and pick one or more files from your device (several only when the field allows more than one).
2. The message "Added" appears, and every file is listed by name above the button. The x on a file removes it again.
3. Files are added to the ones already there, up to the maximum the project sets for this field (10 when nothing else is set). Then the button is off and a message says so.

Good to know:
- Files work without a connection. They are kept on your device and sent later with the task.
- The project sets the allowed file types. A file of another type is refused with a message. When the project sets no types, the picker offers images (PNG, JPEG, WebP, GIF).
- Unlike photos, the file is stored as it is.
- Everything works with the keyboard: Tab reaches the button, Enter or Space opens the picker.
