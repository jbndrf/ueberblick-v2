# Wenn eine Übermittlung abgelehnt wird

Die App prüft jede Aufgabe schon auf deinem Gerät und dann noch einmal auf dem Server. Wird eine Übermittlung abgelehnt, steht in einem einfachen Satz in deiner Sprache, warum: im Formular, in der Liste der ausstehenden Änderungen und über einem Eintrag. Der Satz enthält keinen Code. Betrifft die Ablehnung ein Feld, nennt eine zweite Zeile es („Feld: Höhe“). Lehnt schon dein Gerät die Änderung ab, erscheint über dem Formular ein rotes Feld „Nicht möglich“ mit dem Grund; es wurde nichts gespeichert, das Formular bleibt mit deinen Eingaben offen, „Schließen“ blendet das Feld aus. Lehnt der Server später ab, bleibt die Änderung mit ihren Werten auf deinem Gerät: am Objekt und unter Einstellungen → Profil → „Ausstehende Änderungen“ siehst du den Grund, „Erneut senden“ und „Verwerfen“.

| Das liest du | Was du tun kannst |
|---|---|
| Der Eintrag oder die Aufgabe existiert nicht mehr. | Karte neu öffnen und den Eintrag prüfen. |
| Dieser Eintrag ist archiviert oder gelöscht. | Eine Administratorin um Wiederherstellung bitten oder einen neuen Eintrag anlegen. |
| Die Aufgabe ist im aktuellen Zustand des Eintrags nicht verfügbar. | Eintrag neu öffnen und prüfen, welche Aufgaben angeboten werden. |
| Du darfst diese Änderung nicht vornehmen. | Die Verwaltung fragen, ob deine Rolle die Aufgabe ausführen soll. |
| Du darfst dieses Feld nicht ändern. | Das Feld unverändert lassen. |
| Diese Eigenschaft darfst du nicht sehen. | Die Verwaltung fragen, ob deine Rolle die Eigenschaft sehen darf. |
| Diese Eigenschaft gibt es nicht. | Die Verwaltung informieren. |
| Ein Pflichtfeld fehlt. | Feld ausfüllen und erneut senden (ein Text ohne Inhalt in jeder Sprache zählt als leer). |
| Ein Wert ist ungültig. | Wert anpassen. |
| Die Änderung ist unvollständig und wurde nicht übernommen. | Eingaben im Formular prüfen (bei einer Ablehnung durch den Server: die abgelehnte Änderung verwerfen und die Aufgabe neu ausführen). |
| Ein zugehöriger Eintrag existiert nicht mehr. | Lage des Eintrags prüfen. |
| Die Aufgabe passt nicht zu diesem Eintrag. | Die Aufgabe am richtigen Eintrag starten. |
| Es fehlt ein Standort. | Standort setzen. |
| Du hast die maximale Anzahl an Einträgen erreicht. | Die Verwaltung um ein höheres Limit bitten. |
| Die Änderung löst zu viele Folgeänderungen aus und wurde nicht übernommen. | Die Verwaltung informieren. |
| Die Änderung betrifft zu viele Einträge auf einmal und wurde nicht übernommen. | Die Verwaltung informieren. |
| Beruht auf einer abgelehnten Änderung. | Zuerst die abgelehnte Änderung beheben. |
| Die Datei ist beim Hochladen beschädigt worden. / Die Datei wurde nicht hochgeladen. Bitte erneut senden. | Erneut senden. |
| Die Datei ist zu groß. | Eine kleinere Datei wählen. |
| Die Datei ist nicht mehr auf diesem Gerät. Bitte neu auswählen. | Datei neu auswählen. |
| Für den Import fehlt das Koordinatenreferenzsystem. | Die Verwaltung informieren. |

## Folgeänderung abgelehnt

Hast du offline einen Eintrag angelegt und danach weitere Änderungen an ihm vorgenommen, und der Server lehnt das Anlegen ab, verschwindet der Eintrag von der Karte. Die späteren Änderungen daran stehen in Einstellungen → Profil → „Ausstehende Änderungen“ mit dem Zeichen „Folgeänderung abgelehnt“. Der Text beginnt mit „Beruht auf einer abgelehnten Änderung.“ und nennt dann den Grund der abgelehnten Änderung. Sie werden nicht gesendet. Mit „Verwerfen“ entfernst du sie, mit „Erneut senden“ legst du sie neu in die Warteschlange. Der Titel einer solchen Zeile springt nicht zur Karte, solange der Eintrag nicht auf dem Gerät ist.

Eine Ablehnung, die diese App noch nicht kennt (zum Beispiel von einem neueren Server), lautet „Die Änderung wurde nicht übernommen.“

Wird eine Übermittlung abgelehnt, bleiben alle anderen Änderungen daraus ungespeichert: Eine Änderung wird ganz oder gar nicht übernommen.
