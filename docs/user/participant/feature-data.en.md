# Looking at the data of a feature

Tap a feature on the map and switch to the **Data** tab. It lists every property your role may see, in the project's order. The location and the stage are not listed: the location is the position on the map and the stage belongs to the history in Aktivität (as in v3, which never showed either as a row).

- The property's name stands above each value in capitals, the value below it in a box.
- Long text keeps its line breaks and gets a taller box.
- Choices appear as badges in the order the project declares the options, not the order they were tapped.
- Dates, numbers and times appear in your language (in English Nov 3, 2026 and 1,234.5, in German 03.11.2026 and 1.234,5), and so do the names of the properties when the project named them in that language. Without a translation the name appears in the project's default language; a property with no name at all shows its key. The list shows the same values as Data (for example the label of a choice instead of its key), and your role in Settings shows under its name.
- A property without a value shows "No value" in italics. An empty file field shows "No file". Photos appear as a strip of pictures; if a preview cannot be loaded, the strip shows the original picture, and only if that is missing too, a grey placeholder.
- A person shows by name, in Data and in the list. If your device does not know the name, it says "Someone", never an id. Switch the language and names, relations and "2h ago" change at once, without a reload.
- When a value changed more than once, "n changes" appears below it. Tapping it opens the "History" with the earlier values, newest first; a cleared value shows as "Cleared". The history keeps the last ten values.

## Sub-tabs in Data

When the project has spread the properties over tabs, a strip of tabs sits above the values. The first is called "Data", the others carry the project's names; if the strip is wider than the screen, swipe it sideways. A tap switches the tab. A tab without a single value does not appear, and neither do properties the project hides or shows only under a condition (for example a property only once another has a value). When the project has made no tabs, you see just the list. If no tab has a value, it says "No data yet". The project also decides whether a value's count reads "n readings" (each value is a new measurement) or "n changes".

Properties the project put on the same row stand next to each other, each at half width, on a phone too. All others take the full width.
