# Work with a list

Every list in the admin area (participants, roles, data) works the same way; the existing lists are switched over later.

- **Search:** Type in the "Search" field. The list shows only rows with matching text.
- **Sort:** Click a column heading. First click ascending, second descending, third removes the sort.
- **Filter:** The filter button next to a heading lists the column's values with counts. Type to narrow the values, move with the arrow keys and press Enter (or click) to tick one or more; "Clear filter" at the end of the list removes that column's filter. "Clear filters" removes search and all filters.
- **Edit:** Switch on "Edit mode". Click an editable cell to open it; Enter saves, Esc cancels. Multi-line text cells open a text box where Enter adds a line and leaving the box saves.
- **Pick several (roles and similar):** In Edit mode a click on the badges opens a picker with search. On a phone it fills the screen ("Done" closes it); on a computer it drops down, with arrow keys and Enter. Typing a name that does not exist offers "Create ..." where the column allows it. Nothing is saved until you press "Save" under the cell (one "Saved" message); "Cancel" discards your changes. Cells with nothing picked show a short hint text (for roles: that no role is assigned).
- **Add a row:** The last row is empty. Fill the cells and confirm with the check mark ("Add row"). Required cells have a red outline while they are missing.
- **Select several rows:** Tick "Select row"; with Shift held, everything up to the last clicked row is selected.
- **Row menu:** The "Open menu" button at the end of a row offers "Edit", further actions and "Delete".

Long lists draw only the rows in view; scrolling stays smooth.
