# Accessibility statement

{{operator_name}} works to make the application "Überblick" ({{application_url}}) accessible in line with the German Disability Equality Act and the accessible information technology ordinance (BITV 2.0). This statement applies to {{scope}}.

## Compliance status

The application is **partially** compliant with BITV 2.0 (EN 301 549, WCAG 2.1 level AA). The reasons are listed under "Content that is not accessible".

## Content that is not accessible

- **Page titles (WCAG 2.4.2):** the start page and the builder have no page title. A fix is planned: {{date_titles}}.
- **Reflow at 320 px (WCAG 1.4.10):** the builder needs horizontal scrolling on a very narrow display. The builder is a screen tool for administrations. A fix is planned: {{date_reflow}}.
- **Project content:** labels, photos and help texts are set by the project owners. This statement covers them only where {{operator_name}} wrote them.

## Accessible features

- Full keyboard operation, a skip link to the content, a visible focus.
- Map zoom and "my position" as large buttons, and the map is described as pointing to the list.
- A list view as the alternative to the map.
- A high-contrast outdoor mode (contrast at least 7:1) and target sizes of at least 44 px, 56 px for primary actions.
- Status messages (online, offline, not sent, refused) as text and symbol, not colour alone.
- Languages: German and English.
